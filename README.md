# Barcode Battle v0.7

## バトルを完全自動化
通常攻撃 / 特殊攻撃 / 防御 の手動操作を廃止しました。

### 通常バトル
- 「バトルスタート」を押す
- AIが自動で行動を選択
- 素早さ順に双方が行動
- 決着まで自動進行

### ∞ダンジョン
- 各階で「この階を自動バトル」を押す
- AIが決着まで自動で戦闘
- 勝利後は「次の階へ」または「撤退」を選択
- 次の階でも自動バトル開始

## AI行動
HP、相手HP、攻撃性能などを見ながら
- 通常攻撃
- 特殊攻撃
- 防御
を自動選択します。

既存の高品質モンスター、Lv、EXP、ゴールド、∞ダンジョン、強化ショップ、ホーム画面アイコンは維持しています。
v0.6以前の同端末データも引き継ぎます。
