# Barcode Battle v1.5 — Identity & Item Detail

## 同じモンスターの見分け改善
- ニックネーム変更を追加（最大12文字）
- 元の種族名は保持
- 個体IDを表示
- BOXカード・出撃選択カードにHP/攻撃/防御/素早さを簡易表示
- 装備アイコン＋装備名をカードに表示
- 型 / 属性 / Lv / 出撃中表示を維持
- バトル中もニックネーム表示

## アイテム性能を明確化
装備説明に「発動条件・確率・効果・ターン数」を表示。

例：
- 灼熱コア
  - 攻撃上昇
  - 特殊攻撃時に一定確率で炎上付与
  - 炎上は数行動継続
  - 行動ごとに最大HP割合ダメージ
- 毒牙コア
  - 特殊攻撃時に毒付与
- 鋼心コア
  - 状態異常を受ける確率を軽減
- 雷光の靴 / 蒼雷ソード
  - 特殊攻撃時に麻痺付与

旧バージョンで入手済みの装備も、名前から新効果へ自動変換します。
