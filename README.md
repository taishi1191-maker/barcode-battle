# Barcode Battle v0.5

## 今回のアップデート
ゲーム内の召喚モンスターを、以前の簡易SVGから高品質イラストへ差し替えました。

- スライム
- ドラゴン
- ビースト
- バード
- ゴースト
- マシン
- ナイト

の7種族に、それぞれ専用の高品質キャラ画像を設定しています。

さらに、
- 属性によって色味が変化
- ★4以上は発光感アップ
- ★5はさらに豪華な表示
- BOX、図鑑、通常バトル、∞ダンジョン内でも同じ高品質キャラを表示
- ホーム画面アイコン、∞ダンジョン、Lv、EXP、ゴールド、永続強化はそのまま維持
- v0.4以前の同端末データを引き継ぎ
