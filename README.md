# Barcode Battle v0.9 — Synergy & Status

## 大型バトル拡張
- 特殊能力を24種類に拡張
- 特殊能力の効果数値を個体ごとにランダム化
- 1体が最大4個の特殊能力を所持
- ★が高いほど複数能力を持ちやすい
- Lv上限を100へ拡張

## ステータス新スケール
Lv1からHPは数百〜4桁級。
攻撃・防御・素早さも数百級まで生成。

## バーコード固定の「型」
バーコードから以下のような性能傾向が固定されます。
- 万能型
- 鉄壁要塞型
- 重戦車型
- 超火力型
- 神速型
- 不沈壁型
- 暗殺型
- 怪力型

同じバーコードでも個体値・特殊能力・能力数はランダムです。

## 状態異常
- 炎上
- 毒
- 麻痺
- 攻撃DOWN
- 防御DOWN

## シナジー能力
例：
- 炎上中の敵に追加ダメージ
- 毒状態の敵に追加ダメージ
- 状態異常の敵を攻撃すると回復
- 毒状態の敵がいると自己再生
- 自分が炎上すると攻撃力上昇

## 既存データ
v0.8以前のモンスターは新スケールへ自動変換し、
旧特殊能力も引き継ぎ用能力として保持します。

GitHub更新は index.html / sw.js / manifest.webmanifest / README.md の4ファイルでOKです。
assets画像は変更ありません。
