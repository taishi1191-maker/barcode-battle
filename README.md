# Barcode Battle v1.0 — Adventure Update

## 主な変更
- お気に入りと出撃モンスターを分離
- お気に入りは複数体に設定可能
- 通常バトル画面で出撃モンスターを選択
- ∞ダンジョン画面で挑戦モンスターを選択
- 冒険モード追加
  - 第一章「バーコードの森」
  - 5ステージ
  - クリアで次の道を解放
  - 毒・素早さ・防御・ボスなどステージ特性あり
  - 初回クリア報酬あり
- モンスターの見た目フォームを5種類追加
  - ノーマル / ロイヤル / クリスタル / シャドウ / プライマル
- iPhone操作性改善
  - 下部固定ナビ
  - Safe Area対応
  - 44px以上のタップ領域
  - 横スクロールの出撃モンスター選択
  - iOS入力ズーム対策
  - 初期化ボタンを設定内へ移動
  - 対応端末では軽い振動フィードバック
