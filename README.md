# Barcode Battle v2.0.2 — Quick Continue

## 修正内容
戦闘終了後に、全画面バトルを閉じずそのまま次へ進めるようにしました。

- COMバトル → 「次の対戦」
  - 新しいCOMを生成
  - そのまま次のバトル開始
- 冒険 → 「次のステージ」
  - 最終ステージ等では「再戦」
- ∞ダンジョン → 「次の階へ」
  - 次の階へ進み、そのまま戦闘開始
- 「終了」で通常画面へ戻る

これで1戦ごとに「戻る」必要はありません。

GitHubではZIPを解凍して10個をまとめてルートへアップロード・上書きしてください。
既存assetsは削除しないでください。
